    SUBMIT YOUR SITE

    no PR skills required. open an issue, fill the form, an action validates + opens a PR.

    1. Open Issues → New issue → "Submit a site".
    2. Fill: site name, URL, description, category, tags, platform.
    3. An action validates the URL, rejects duplicates, and adds the site automatically.
    4. A data refresh runs and the site appears in the directory.
